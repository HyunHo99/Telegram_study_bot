# 📚 Telegram 스터디 봇

증권사 리포트 스터디를 위한 텔레그램 단톡방 봇입니다.
멤버 레벨별 과제(데일리/위클리) 제출을 관리하고, Notion 에 자동 아카이빙하며,
매주 월요일 아침 벌금을 자동 집계·공지합니다.

## ✨ 기능

1. **레벨별 과제 관리**
   - 멤버마다 레벨(1~3)을 등록/변경
   - 레벨별로 데일리/위클리 과제 요구량과 벌금이 다름
   - 데일리/위클리 제출, 이번 주 진행 상황 확인
   - 위클리 과제 방향(주제) 공지/확인

2. **Notion 자동 아카이빙**
   - 제출 시 상위 페이지 아래에 **주차별 페이지**(예: `2026-W30`)를 만들고,
     각 제출물을 그 주차 페이지의 **하위 페이지**로 아카이빙

3. **주간 벌금 자동 집계**
   - 한국시간 매주 **월요일 08:00**, 지난 주 미달자를 집계하여 단톡방에 공지

## 📋 레벨 규정

| 레벨 | 데일리 과제 | 위클리 과제 | 데일리 벌금 | 위클리 벌금 |
|:---:|:---:|:---:|:---:|:---:|
| 레벨3️⃣ | 주 3회 | 1주 1회 | 1,000원 | 3,000원 |
| 레벨2️⃣ | 주 3회 | 2주 1회 | 1,000원 | 5,000원 |
| 레벨1️⃣ | 주 3회 | 없음 | 2,000원 | — |

> 규정 수치는 `bot/config.py` 의 `LEVEL_RULES` 에서 바로 수정할 수 있습니다.

## 🚀 설치 및 실행

> ☁️ **서버가 없어도 됩니다.** 텔레그램은 봇 코드를 호스팅해주지 않으므로 봇을
> 24시간 켜둘 곳이 필요한데, 무료 VM에 올리는 방법을 [`deploy/README.md`](deploy/README.md)
> (Oracle Cloud 무료 VM)에 단계별로 정리해 두었습니다.

```bash
# 1. 의존성 설치
pip install -r requirements.txt

# 2. 환경변수 설정
cp .env.example .env
# .env 파일을 열어 토큰/ID 입력

# 3. 실행
python run.py
```

### 환경변수 (.env)

| 변수 | 설명 |
|---|---|
| `TELEGRAM_BOT_TOKEN` | BotFather 발급 봇 토큰 (필수) |
| `NOTION_TOKEN` | Notion 인테그레이션 토큰 (아카이빙 사용 시) |
| `NOTION_PARENT_PAGE_ID` | 아카이빙 상위 페이지 ID |
| `NOTION_ENABLED` | Notion 연동 on/off (`1`/`0`) |
| `ANNOUNCE_CHAT_ID` | 벌금 공지 단톡방 ID (미설정 시 멤버가 등록된 모든 방) |
| `ADMIN_USER_IDS` | 관리자 user_id 목록(쉼표). 미설정 시 그룹 관리자 허용 |
| `TIMEZONE` | 기본 `Asia/Seoul` |
| `DB_PATH` | SQLite 경로 (기본 `data/study_bot.db`) |

### Notion 연동 준비

1. https://www.notion.so/my-integrations 에서 인테그레이션을 만들고 토큰 발급
2. 아카이빙할 상위 페이지의 `⋯ → 연결(Connections)` 에서 해당 인테그레이션 연결
3. 페이지 URL 의 32자리 ID 를 `NOTION_PARENT_PAGE_ID` 에 입력

## 💬 명령어

**멤버**

| 명령 | 설명 |
|---|---|
| `/register [레벨]` | 멤버 등록 (레벨 생략 시 1) |
| `/daily <내용>` | 데일리 과제 제출 (리포트 메시지에 답장하며 `/daily` 도 가능) |
| `/weekly <내용>` | 위클리 과제 제출 |
| `/status` | 이번 주 내 과제 진행 상황 |
| `/mylevel` | 내 레벨/규정 |
| `/members` | 멤버·레벨 목록 |
| `/rules` | 레벨별 규정 |
| `/topic` | 이번 주 위클리 과제 방향 |

**관리자**

| 명령 | 설명 |
|---|---|
| `/setlevel <레벨>` | (대상 메시지에 답장) 해당 멤버 레벨 설정 |
| `/setlevel <user_id> <레벨>` | user_id 로 레벨 설정 |
| `/topic <내용>` | 위클리 과제 방향 설정·공지 |
| `/fine` | 지난 주 벌금 즉시 집계·공지 |
| `/fine_preview` | 이번 주(진행 중) 기준 벌금 미리보기 |

## 🧱 구조

```
bot/
├── config.py          # 환경설정 + 레벨/벌금 규정
├── database.py        # SQLite 저장소
├── weeks.py           # ISO 주차/주기 계산
├── fines.py           # 벌금 집계 로직
├── notion_sync.py     # Notion 아카이빙
├── telegram_utils.py  # 공통 유틸
├── handlers.py        # 명령 핸들러
├── scheduler.py       # 월요일 08:00 벌금 스케줄
└── main.py            # 진입점
run.py                 # python run.py
```

## 📝 참고

- 위클리가 **2주 1회**(레벨2)인 경우, 2주 주기의 마지막 주 월요일에만 위클리 벌금을 정산합니다.
- 제출 최소 분량(300자)은 **거부하지 않고** 글자 수만 표시하며, 미달 시 안내 문구만 붙습니다.
- 벌금 집계 기준 주는 "월~일(ISO 주차)" 입니다.
